
# Lights Out Solver

A personal engineering project to design and build a machine that solves a 5 × 5 Lights Out puzzle.

## Objectives

- Implement a Lights Out solver using C++ and linear algebra.
- Design a physical 5 × 5 LED display for recommended moves.
- Integrate user input, embedded software, and electronics.
- Design a PCB using Altium Designer.
- Create mechanical drawings using AutoCAD.
- Document and test the finished system.

## Current Status

Initial software development and project planning.

## Technologies

- C++
- Git and GitHub
- Visual Studio Code
- Altium Designer
- AutoCAD

## Project Structure

- `src/` — source code
- `docs/` — requirements and engineering documentation
- `tests/` — test cases and verification
- `hardware/` — electronic and mechanical design files
